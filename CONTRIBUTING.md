# Contributing

Thanks for your interest in contributing to Encrypt Social!

## Reporting bugs

Open an issue with:

1. **Clear description** of the problem
2. **Steps to reproduce**
3. **Expected vs. observed behavior**
4. **Firefox version** (`about:support`)
5. **Console logs** prefixed with `[EncryptSocial]`

## Suggesting improvements

Open an issue tagged `enhancement` describing:

- The problem the improvement solves
- The proposed approach
- Alternatives considered

## Submitting code

1. Fork the repository
2. Create a branch: `git checkout -b feat/feature-name`
3. Commit following [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat: add X`
   - `fix: correct Y`
   - `docs: update Z`
   - `refactor: simplify W`
4. Push and open a Pull Request

## Code standards

- **JavaScript**: ES2020+, no frameworks
- **Formatting**: 2 spaces, semicolons, single quotes
- **Naming**: `camelCase` for variables/functions, `UPPER_SNAKE` for
  constants
- **Comments**: in English

## Areas that need help

Check issues tagged `good first issue` and `help wanted`.

## Code of conduct

Be respectful. Disagree with the code, not the person.
